# Photon Pong

A neon-inspired Pong game built with HTML, CSS, JavaScript, and the HTML5 Canvas API.

## About the Project

Photon Pong originally started as an academic project for the Digital Games course at CEFET/NF (Federal Center for Technological Education of Rio de Janeiro – Nova Friburgo campus).

Inspired by the classic Pong, the project was developed to explore game development concepts using web technologies, including JavaScript for game logic and HTML5 Canvas for rendering.

Beyond its academic origins, Photon Pong is an ongoing personal project that I intend to continuously improve, focusing on code quality, gameplay mechanics, and user experience.
